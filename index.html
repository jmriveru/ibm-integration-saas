01 · Qué se contrata

Una plataforma, muchas capacidades

IBM Integration SaaS es una plataforma de integración como servicio (iPaaS). Usted no administra infraestructura: IBM lo hace. Conecta aplicaciones, automatiza flujos, gestiona APIs, intercambia documentos B2B, transfiere archivos y maneja eventos desde una sola nube.

04 · Segundo componente

Uso: RU según lo que fluye por la plataforma

Cada métrica tiene su unidad de conteo y dos tramos de consumo: el volumen anual más alto consume menos RU por bloque. Producción y no-producción se cuentan por separado, y en no-producción obtiene el doble de volumen por las mismas RU.

Métrica principal

Transacciones de integración

webMethods y App Connect Enterprise (ACE)

  • Se genera 1 transacción cada vez que se ejecuta un flujo.
  • Un flujo que dura más de 60 segundos suma 1 transacción adicional por cada 60 segundos extra. Por ejemplo, un flujo de 120 segundos cuenta 2 transacciones.

05 · Tercer componente

Conexiones: Hybrid Control Plane y red privada

Si usted ejecuta integraciones on-premises o en otras nubes pero las administra desde IBM Integration SaaS, cada runtime remoto consume pocas RU. La conectividad por red privada consume RU por entorno.

Runtimes remotos (Hybrid Control Plane)

Cada Integration Runtime (IR) o API Gateway remoto conectado al control plane.

VolumenRU por IR / API GW
Primeros 100 por año2 RU / mes
Sobre 100 por año1 RU / mes

Cómo se mide

  • Se mide por el peak del mes: se toma la cantidad máxima de runtimes remotos conectados en el mes calendario.
  • Event Gateways, DataPower Gateways y webMethods Integration Edge Runtimes que se usan como software habilitador no se incluyen en el cálculo de RU.

07 · Mensajes de IA

DataPower Interact Gateway: el control de su tráfico de IA

Si usted quiere mensajes de IA, el tráfico hacia modelos, herramientas MCP y agentes pasa por DataPower Interact Gateway. Este componente necesita una instancia de API Connect como prerrequisito.

Cómo se consume

6 RU
por cada 1.000.000 de mensajes, hasta 1.000.000.000 al año
4 RU
por cada 1.000.000 de mensajes sobre 1.000.000.000 al año

En no-producción, 2.000.000 de mensajes consumen las mismas RU que 1.000.000 en producción.

Ejemplo: 10.000.000 de mensajes de IA al año en producción = 10 bloques de 1.000.000 × 6 RU = 60 RU, además de las RU de la instancia de API Connect.
08 · Compromiso de servicio

SLA: disponibilidad y créditos

IBM mide la disponibilidad mensual como (minutos totales del mes − minutos fuera de servicio) ÷ minutos totales del mes. Si IBM no cumple la meta, usted recibe un crédito equivalente a un porcentaje de la cuota mensual de su suscripción.

Exclusiones a considerar

Los créditos no aplican a interrupciones causadas por:

  • Sus propios endpoints de API
  • APIs de gestión
  • Analítica de uso
  • AI Agents o AI Assistants

Las funciones etiquetadas como "Tech Preview" están excluidas del SLA y pueden no tener soporte; IBM puede cambiarlas o retirarlas sin aviso.
