Alta disponibilidad, despliegue híbrido y seguridad

IBM Integration SaaS separa el plano de control (cloud) del plano de ejecución (distribuido), permitiendo gobernar centralmente mientras se ejecuta localmente en las plantas de CMPC.

A1Score 5/5

Alta disponibilidad y SLA

  • ✓SLA contractual 99,9% de disponibilidad (contrato i126-9947)
  • ✓2 réplicas de Cloud Runtime por defecto
  • ✓3 zonas de disponibilidad por región AWS/Azure
  • ✓Failover automático multi-zona
A2Score 5/5

Modelos de despliegue

  • ✓Cloud Runtime iPaaS (AWS 5 regiones + Azure)
  • ✓Edge Runtime on-premises en redes de planta
  • ✓Hybrid Control Plane: gestión unificada cloud + on-prem
  • ✓Conexión segura desde redes internas sin exponer datos
A3Score 5/5

Patrones de integración

  • ✓API-led: API Connect con capas System / Process / Experience
  • ✓EDA / Eventos: Kafka (Event Streams), MQ, Event Endpoint Mgmt
  • ✓Batch: MFT, SFTP, procesamiento masivo con scheduling
  • ✓ETL/ELT: IBM StreamSets, database integration
A4Score 5/5

Seguridad y compliance

  • ✓TLS / mTLS end-to-end en tránsito; cifrado en reposo
  • ✓RBAC — control de acceso por roles; secrets management
  • ✓Certificaciones: SOC 2, HIPAA, GDPR
  • ✓Keystores/Truststores gestionados; audit logging completo
  • ✓AWS PrivateLink para conectividad de red privada

Edge / On-premise para plantas CMPC

IBM Integration incluye adaptadores certificados para SAP y Salesforce con soporte de todos los protocolos solicitados en la matriz. El portfolio alcanza más de 400 conectores pre-construidos.

C1Score 5/5

SAP — Adapter nativo certificado

Adaptador webMethods para SAP con soporte completo de protocolos SAP, incluyendo S/4HANA Cloud vía OData.

  • ✓RFC — Remote Function Call; llamadas sincrónicas a funciones ABAP
  • ✓BAPI — Business API; catálogo de BAPIs SAP preconfiguradas
  • ✓IDoc — Intermediate Documents; integración B2B con SAP bidireccional
  • ✓OData — Conectividad REST para S/4HANA Cloud y SAP BTP
  • ✓SAP Cloud Connector compatible con arquitectura SAP BTP
  • ✓Sincronización bidireccional: órdenes, confirmaciones, maestros
  • ✓Control transaccional e idempotencia nativos
C2Score 5/5

Salesforce — Adapter nativo certificado

Adaptador Salesforce para integración de procesos comerciales, sincronización de datos y procesamiento de eventos en tiempo real.

  • ✓REST / SOAP — Operaciones CRUD estándar sobre objetos Salesforce
  • ✓Bulk API 2.0 — Operaciones masivas asincrónicas de alto volumen
  • ✓Pub/Sub API — Suscripción a Platform Events en tiempo real
  • ✓CDC (Change Data Capture) — Captura de cambios en registros
  • ✓Autenticación OAuth 2.0; gestión de límites de API Salesforce
  • ✓Streaming de eventos gestionado; automatización bidireccional

Además de SAP y Salesforce: 400+ conectores pre-construidos — REST, SOAP, bases de datos, archivos planos, protocolos industriales y más.
